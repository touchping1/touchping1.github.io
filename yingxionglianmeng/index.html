系统兼容性指南

确认您的设备是否支持英雄联盟 Mac 版运行

🍎

Apple Silicon (M1/M2/M3)

支持原生运行，无需虚拟机，性能最佳。

  • 支持 macOS Monterey, Ventura, Sonoma
  • 原生 OpenGL 3.0+ 支持
  • 建议内存：16GB 起步
  • 显卡：集成显卡即可流畅运行
💻

Intel 处理器 Mac

使用 Boot Camp 或虚拟机运行。

  • 支持 macOS 10.13 - 10.15
  • Boot Camp 方案：安装 Windows 10/11
  • 虚拟机方案：Parallels Desktop / VMware Fusion
  • 注意：Intel Mac 已停止系统更新支持
🔄

ARM 版 Windows (Surface Pro X 等)

通过虚拟机运行，需配置特定环境。

  • 需使用 Windows on ARM
  • 推荐虚拟机：VMware Workstation Pro
  • 游戏兼容性：需开启虚拟化加速
  • 注意：可能存在部分启动问题

安装与运行指南

针对不同设备系统的详细操作步骤

1

下载客户端

请访问官方网站或指定的 Mac 资源下载站。确保下载的安装包文件名为 League of Legends.dmg，避免下载到病毒或捆绑软件。

2

安装与激活

将 .dmg 文件拖入“应用程序”文件夹进行安装。首次运行时，系统可能会弹出安全提示，请选择“打开”以允许运行。首次启动需要联网验证账号。

3

Intel Mac 用户特殊设置

如果您使用的是 Intel 芯片 Mac，建议使用 Parallels Desktop 虚拟机安装 Windows 11，并开启“3D 图形加速”功能，这比 Boot Camp 更便于调试和回退。

4

解决闪退或黑屏问题

如果游戏启动后闪退，请尝试以下命令重置网络缓存（适用于 Mac 原生客户端）：

cd ~/Library/Application\ Support/League\ of\ Legends && rm -rf RADS && open /Applications/League\ of\ Legends.app

性能优化设置

提升帧率与降低延迟的实用技巧

1

关闭后台应用

Mac 系统资源有限，运行大型游戏时请关闭浏览器、邮件、Safari 标签页以及系统更新进程，释放内存和 CPU 占用。

2

系统设置调整

  • 电池模式： 插电运行，并确保“高性能模式”已开启。
  • 显示器设置： 在系统设置中将“自动调节亮度”和“降低白点”关闭，确保色彩配置为“sRGB”。
  • 触控板/鼠标： 在游戏设置中调整灵敏度，确保不发生鼠标漂移。
3

游戏内画质设置

对于 M1/M2 芯片，建议将“阴影质量”和“特效质量”设为“中”或“低”，将“垂直同步”关闭，以获得更稳定的帧率。

常见问题 (FAQ)

关于英雄联盟 Mac 版的疑问解答

英雄联盟 Mac 版是原生支持吗？ +
目前官方推出的 Mac 版客户端是基于 OpenGL 技术构建的，针对 Apple Silicon 芯片进行了优化，可以原生运行，无需虚拟机。
M1 MacBook Air 能流畅运行吗？ +
可以。搭载 8GB 内存和 7 核或 8 核 GPU 的 MacBook Air 在设置中画质适中时，可以保持 60FPS 左右的流畅度。
闪退了怎么办？ +
请尝试删除游戏客户端缓存文件夹（Library/Application Support/League of Legends），然后重新启动游戏。
可以在 iPad 上玩吗？ +
官方目前没有推出 iPad 原生版本。如果您使用 iPad，通常需要通过 Parallels Desktop 运行 Windows 虚拟机，体验并不理想。
